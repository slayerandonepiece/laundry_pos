## Behaviour that must survive unchanged

- Native `<dialog>` + `showModal()` focus trapping.
- Escape, backdrop click and the close button all use the same close path.
- Focus returns to the trigger on close.
- Dirty forms keep the existing "Discard changes?" guard.
- Size variants: default and wide.
- Confirmation dialogs (Lock / Delete / Archive / Deactivate / Reset-password and
  the dirty-form discard) are compact native confirmation dialogs — a separate
  shape from the centered form dialogs. Keep both shapes.
- `.ad-root.ad-confirm-dialog` needs higher specificity than the generic
  `.ad-root{max-width:100%}` mobile-containment rule. A past QA pass found this
  exact bug; do not reintroduce it.

## `Panel` survives — but only just

`Panel` stays **solely** for the two PDF slide-over viewers (`InvoicePdfViewer`,
`OrderInvoicePdfViewer`). The Owner Workspace 2.0 spec bans side panels for
create/edit flows. Do not delete `Panel`; do not keep using it for anything else.
