## How a screen phase works

1. `graft ask "<screen> components" --source` to locate the files. Do not open
   whole files.
2. Replace this screen's markup with the shared library from
   `src/features/shared/ui/` plus inline Tailwind utilities. No new CSS file
   unless it is a genuine escape hatch (`::backdrop`, `@media print`, `@page`,
   third-party override) — and then it carries a comment saying why.
3. Retire this screen's `style={{…}}` blocks and any hardcoded hex that restates
   a token.
4. Delete the CSS families this screen was the last consumer of. Prove it with
   `graft grep`, not by eye.
5. Run the gate. Commit. Update `../STATUS.md`.
