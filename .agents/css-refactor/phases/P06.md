## Objective

One shell implementation, configured per role. This is the phase that delivers
the user's explicit requirement: a unique sidebar across roles, with the Store
Owner / Employee sidebar showing the **live store name** instead of a hardcoded
brand, identical on every screen.

## Scope

`src/features/shared/ui/AppShell` —
`AppShell · Sidebar · Topbar · MobileDrawer · NavItem · Brand`

| Prop | Super Admin | Workspace |
| --- | --- | --- |
| `brand` | `StoreOps` / `PLATFORM ADMIN` | **live store name** / `STORE WORKSPACE` |
| `nav` | 7 platform links | role-filtered (owner vs employee) |
| `topbar` | search + `⌘K`, bell, avatar | store switcher, outlet switcher, avatar |
| `footer` | user + `Super Admin` | user + role |

Both `AdminChrome` and `SuperAdminChrome` swap onto it. Delete
`.ad-sidebar`/`.ad-topbar` and the `.soa .side`/`.top` families.

## No new data plumbing is needed

The store name already resolves in `src/app/(workspace)/layout.tsx` via
`resolveStoreSelection(true)` and is passed to `AdminChrome` as `storeName`
today. `AdminChrome` currently falls back to `'Your store'`. Wire the existing
value through — do not add a query, a prop chain or a context.

## What this phase retires

- The emoji nav glyphs at `AdminChrome.tsx:14` → real SVG `Icon` (Phase 2).
- **One of the two mobile-drawer focus-trap implementations.** `AdminChrome`'s
  `MobileNavigation` and `SuperAdminChrome`'s `MobileNav` are near-identical
  native-`<dialog>` copies. Keep one.

## Behaviour that must survive — re-verify explicitly (plan §5.2)

- Signed-out `/` redirects to `/login`; owner sign-in reaches `/`; reload retains
  the session; signed-in `/login` returns to the role's home; logout reaches
  `/login`.
- Employee access checked independently (employees see Sales + Orders only).
- **`AccessBlockedScreen` still renders with nav and logout reachable.** A past
  pass broke logout by nesting the confirmation dialog inside the blocked branch.
  Verify logout works *from the blocked screen*, in both apps.
- The chrome must stay mounted across navigations — it lives in `layout.tsx`, not
  in each page's tree. Only the content column may show the route-level spinner.
- `showAllStoresOption` / outlet-switcher visibility rules are unchanged.
