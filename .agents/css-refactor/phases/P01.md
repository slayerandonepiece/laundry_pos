## Objective

dialogs — and protect the Super Admin freeze for every phase that follows.

**This phase is valuable on its own.** If the project pauses after it, the
reported inconsistency is already resolved.

## Root cause (verified during the audit — do not re-derive)

`src/app/(workspace)/admin/owner-workspace.css` (757 lines) declares nine class
names **unscoped** that `.soa` also defines:

```
card  btn  dialog  dialog-head  dialog-body  dialog-foot  badge  field  shimmer
```

`.soa .card` (specificity 0,2,0) wins on properties both declare — but any
property only `owner-workspace.css` declares bleeds into Super Admin pages
unopposed. Compounding it, the same file declares a global `:root` token block
(`--ink`, `--muted`, `--bg`, …) and is imported **after** `globals.css` in
`src/app/layout.tsx`, so it overrides the app-wide tokens.

## Scope

- Scope every selector in `owner-workspace.css` under a workspace-only root
  (mirroring how `.soa ` prefixes `super-admin.css`), and move its `:root` token
  block onto that scope.
- Delete the dead body of `src/app/globals.css` — roughly 95 of its 101 lines
  are extracted marketing-site CSS (hero, pricing, services, statement, inside,
  location, cta, calc-modal) still shipping on every page.
  **Keep only:** `.ad-route-loading`, `.ad-spinner`, `@keyframes ad-spin`,
  `.ad-route-error-title`, `.content-loading` — all have live consumers. Verify
  each with `graft grep` before deciding; do not trust this list blindly.
- Confirm with `graft grep` that no TSX relies on the unscoped forms.
