## Objective

## Scope

- Create `src/app/app.css` — `@import "tailwindcss"` + the `@theme` block from
  §2.1 of the plan, plus a small base layer (body defaults, `:focus-visible`
  ring, `prefers-reduced-motion`) and the two global `@keyframes` (`spin`,
  `shimmer`). Token values come from `.soa`, because Super Admin is the
  reference. `--border: #e4e8ee` from the owner canvas resolves to
  `--color-line-2`.
- Wire it into `src/app/layout.tsx` **first in the import order**, ahead of the
  existing stylesheets, so nothing it defines can override them yet.
- Commit the untracked `src/features/admin/components/ui/` library as-is
  (13 primitives + `index.ts`, consumed by 15 screens). It is currently
  untracked and could be lost.
- Write `scripts/check-css-orphans.mjs` — lists CSS selectors with no TSX
  consumer, prints a count. Must handle backtick template literals
  (`` className={`stat-tile ${x}`} ``), not just double-quoted `className`.
  **This exact mistake was made during the audit** and produced a false
  "0 references" reading for the whole Owner Workspace 2.0 system.
- Capture reference screenshots of **every** Super Admin screen at 1440 / 768 /
  375 into `.agents/css-refactor/baseline/`. This is the freeze baseline every
  later phase is diffed against.
- Record the baseline CSS line total and orphan count in `../STATUS.md`.

## Why this phase can't be skipped

Tailwind is installed but inert — there is no `@import "tailwindcss"` anywhere
and zero utility classes across 1,176 `className` usages. It compiles nothing
today. And without the screenshot baseline there is no way to prove the Super
Admin freeze held, which is the project's core constraint.
