## RowMenu — two real bugs already fixed here; do not undo them

1. `.menu` collided with a legacy unprefixed rule whose `width:42px;height:42px`
   constrained the popup regardless of item count. `.soa .menu` carries explicit
   `width:auto;height:auto` to defeat it. If the legacy rule is gone by now
   (Phase 1 deleted most of `globals.css`), confirm that with `graft grep`
   before dropping the override — don't assume.
2. `RowMenu.tsx` renders its popup through `createPortal`, positioned from the
   trigger's `getBoundingClientRect()` with `position:fixed`, so it escapes
   clipping by an ancestor table's `overflow`. **The portal target must stay
   inside the `.soa` wrapper** (`.closest('.soa')`) while `.soa` still exists —
   portaling to `document.body` silently breaks the descendant-selector styling.
   Once this component is fully Tailwind-utility based that constraint lifts;
   verify it has, rather than assuming.

## Filter pills must stay real buttons

A past QA pass converted `span[role=button]` filter pills into real `<button>`
elements because they were keyboard-inert. Keep them as `<button>`.

## `.fsearch` is load-bearing for ⌘K

`SuperAdminChrome`'s `focusPageSearch()` targets `.fsearch input`. If the search
field's class changes, update that handler in the same commit or ⌘K silently
stops working.
